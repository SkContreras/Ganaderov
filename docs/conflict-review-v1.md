# Conflict review v1
Web stores latest observed concurrent snapshots (base/local/remote) in scoped syncMeta and displays them to managers. Pure three-way comparison suggests merges of disjoint object fields and ID-keyed collections; no automatic writes or acceptance yet. Audit metadata and lifecycle transitions require domain-specific rules. Snapshot may be stale; never treat proposed merge as authorized. Photos retain metadata only, not backup bytes. Matching versions clear snapshots; other resolution paths may leave stale snapshots. Event RPC conflicts show original request. No retry with altered UUID or blind overwrite. Node tests cover structural comparison; integration and authorization tests pending. Legacy IndexedDB is ranch scoped, not encrypted; do not treat UI permission as a local security boundary. No backend migration.

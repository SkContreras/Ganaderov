# Block C Web
Manual resolution for terminal animal.update, event.update and config.update: fetch current entity, select local fields (unchecked remain remote), refetch, persist new UUID and archive/link original in one encrypted transaction. No automatic reissue of creates, deletes or transitions. Archive recovery returns to review, never pending. Strict opt-in SYNC_RPC_ONLY_V1 blocks legacy bundle/journey/config pushes in syncData and retains snapshots, not a server access cutoff. Do not enable before all UI routes use RPC. Legacy conflicts remain review-only; photo bytes preserved in existing local stores. Tests added, browser/CI pending.

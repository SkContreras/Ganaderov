# Paso 14 — protección local Web
Contexto offline mínimo, limitado a 24 h desde última comprobación online (no renovar offline), ligado a usuario. Contextos antiguos sin timestamp se rechazan. Cambios de cuenta limpian vistas, diálogos, URLs de fotos y contexto anterior; generación de sesión y comprobación de DB evitan algunas respuestas tardías. Ya no importar automáticamente datos de invitado a un rancho: conservar origen para exportación/importación explícita. Service Worker solo guarda assets enumerados, no solicitudes con Authorization/apikey ni rutas arbitrarias. Cache v51. No se borra IndexedDB ni Outbox. IndexedDB por rancho sigue sin cifrar ni separarse por usuario, y código del mismo origen puede leerlo; controles UI no son barrera contra XSS/acceso físico. Revocación offline solo se conoce al reconectar o caducar el contexto, reloj local no es autoridad. Pendientes migración aislada por cuenta, política de eliminación, CSP auditada, carreras restantes, tests de navegador. No desplegar sin comprobar login, cuenta distinta, reconexión, vencimiento, cambio de rancho y conservación de datos.

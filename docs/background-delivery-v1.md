# 16.7 — Web wake acknowledgement
Background Sync now waits up to 25 seconds for a controlled page's acknowledgement, checks the queue for pending RPC operations, and reports a deferred wake rather than treating a missing page as successful delivery. Browser retries are best effort. Existing Web Locks and idempotency remain in effect. A page may close mid-flight; the operation stays durable. A drained acknowledgement covers that page's current account/ranch only, not all local queues. No access or refresh tokens are copied to IndexedDB or sent via postMessage. No direct RPC from the worker without an active page: autonomous closed-PWA delivery remains pending a separately scoped, expiring and revocable server authorization design. No change to backend, no production activation. Requires browser integration tests.
